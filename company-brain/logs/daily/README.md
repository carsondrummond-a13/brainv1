# Daily Logs

Daily logs preserve chronological history. They are not the current dashboard.

## Suggested Filename

`YYYY-MM-DD.md`

## Daily Log Template

### YYYY-MM-DD

#### Summary

- What changed today?

#### Completed

- What got done?

#### New Tasks

- What needs follow-up?

#### Decisions

- Link to `decisions/decision-log.md` if a durable decision was made.

#### Blockers

- What is stuck?

- [Example] Company Brain mockup initialized.
