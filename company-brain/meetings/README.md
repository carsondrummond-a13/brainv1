# Meetings

This folder stores company-level meeting notes and summaries.

## Meeting Note Template

### YYYY-MM-DD — Meeting Title

#### Attendees

- Carson
- John

#### Summary

- Short summary of what happened.

#### Decisions

- Link or copy durable decisions into `decisions/decision-log.md`.

#### Action Items

- [ ] Owner — task.

#### Follow-up

- What should happen next?

## Agent Guidance

- Use project-specific meeting files for project-only meetings.
- Use this folder for company-wide or operating meetings.
- Convert action items into `tasks/active.md` when relevant.
