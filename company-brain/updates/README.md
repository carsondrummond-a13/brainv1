# Updates

Updates are routed messages or summaries that should be preserved beyond Telegram.

## Routes

- `carson-to-John/` — updates from Carson intended for John.
- `John-to-carson/` — updates from John intended for Carson.
- `company-wide/` — updates relevant to both people.

## What Belongs Here

- Important Telegram updates.
- Agent-generated summaries prepared for a person.
- Status changes that should be visible later.

## What Does Not Belong Here

- Secrets or credentials.
- Low-value chatter.
- Unverified claims stated as facts.

## Agent Guidance

- Use clear filenames when adding future updates, such as `YYYY-MM-DD-topic.md`.
- If an update requires action, also add it to the recipient's inbox or `tasks/active.md`.
