# Archive

The archive stores old, inactive, or superseded material.

## What Belongs Here

- Completed project folders that are no longer active.
- Old drafts that should be preserved but not kept in active areas.
- Superseded notes that may still have historical value.

## Rules

- Ask before archiving active material.
- Do not use archive as a trash folder for uncertain deletions.
- Preserve enough context so future agents understand why something was archived.

## Agent Guidance

- Prefer moving material here over deleting it, unless the user explicitly asks for deletion.
- Never archive secrets; secrets should not be committed at all.
