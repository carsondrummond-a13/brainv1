# Project: Company Brain Prototype

Purpose: prove that a small team can use Telegram, agents, cron jobs, skills, GitHub, and Markdown as a lightweight company operating system.

## Simple Pitch

Carson and John can talk to agents in Telegram. Agents can save important updates to GitHub, answer questions from the company memory, and eventually send scheduled cron updates about projects and company status.

## Why This Exists

The goal is to reduce friction in company organization.

Instead of humans manually maintaining docs, future skills should let agents do the heavy lifting:

- save updates
- summarize progress
- track project details
- answer company-memory questions
- send scheduled reminders or reports

## Example Use Cases

- Carson asks: "What projects has John worked on?"
- John sends: "Update the prototype project: we reviewed the workflow today."
- A cron job sends: "Weekly project summary: here is what changed."
- An agent answers: "The main open question is what Telegram updates should be captured."

## Current Status

- Proof-of-concept structure created.
- Keeping the first version intentionally simple.
- Project A is the first test case inside this prototype, focused on grocery-list file updates.

## Next Steps

- Test real Telegram update flows.
- Decide which cron summaries are useful.
- Build skills that know how to read and update this structure.
- Add complexity only when the simple files become limiting.
