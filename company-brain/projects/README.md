# Projects

Project folders hold project-specific memory: status, tasks, decisions, notes, and meetings.

## How To Create a New Project

1. Copy `template/` to a new folder, such as `website-launch/`.
2. Replace example placeholders with real project details.
3. Link the project from relevant dashboards.
4. Keep project tasks here if they are project-specific; copy cross-company tasks to `tasks/active.md` when needed.

## Example Project

- [Example] Website Launch — a future project folder could be named `website-launch/`.

## Project Folder Convention

Use lowercase kebab-case folder names:

- `website-launch/`
- `customer-onboarding/`
- `stripe-integration/`

## Agent Notes

- Do not create a new project folder unless there is enough context to name it clearly.
- Ask before deleting or archiving a project.
